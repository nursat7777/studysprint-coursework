## Goal
As a student I can transfer my data and try the application safely.

## Acceptance criteria
### Export
- [ ] Export is a user-triggered JSON file download.
- [ ] Backup schemaVersion is exactly 1.
- [ ] Backup contains tasks, sessions and settings consistent with current app state.
- [ ] Optional timer snapshot is either validated or omitted consistently.
- [ ] Export preserves task IDs, completion and session timestamps.

### Atomic import
- [ ] Read selected JSON and reject parsing failures visibly.
- [ ] Reject unsupported schemaVersion before replacing data.
- [ ] Reject missing required collections/settings or wrong types.
- [ ] Validate every task, including title/subject lengths, date, priority and boolean completion.
- [ ] Reject duplicate task IDs and duplicate session IDs.
- [ ] Validate session duration range and completion timestamp.
- [ ] Validate configured focus duration as integer 1–120.
- [ ] Validate optional timer remaining seconds and task references according to documented policy.
- [ ] Malformed record in otherwise valid backup rejects entire import.
- [ ] Show replacement confirmation only after complete validation.
- [ ] Cancel replacement leaves tasks, sessions, settings and timer unchanged.
- [ ] Confirmed valid replacement applies complete backup atomically.
- [ ] Invalid import leaves original state and saved data unchanged.
- [ ] Storage error does not falsely report a successful saved replacement.
- [ ] Import errors clearly explain failure and allow retry.

### Demo and verification
- [ ] Demo seeding is an explicit action.
- [ ] Demo never overwrites a nonempty task collection.
- [ ] Demo produces realistic valid tasks useful for demonstrating urgency.
- [ ] Automated tests exercise malformed/version/type/date/ID/range cases.
- [ ] Automated tests exercise valid export/import roundtrip.
- [ ] Component integration tests exercise export payload and replacement-confirmation cancellation.

### Definition of Done
- [ ] Changes committed with genuine history; actual issue linked when available.
- [ ] Independent QA records acceptance evidence; failures fixed before closure.

## Out of scope
Merge conflict resolution or cloud backup.

## Constraints
Depends on 02 and 04; atomic replacement, clear errors.
