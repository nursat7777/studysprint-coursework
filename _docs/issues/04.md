## Goal
As a student I can focus on one task and track finished study sessions.

## Acceptance criteria
### Timer lifecycle
- [ ] Duration accepts integers from 1 through 120 minutes inclusive.
- [ ] Reject zero, negative, fractional, nonnumeric and 121+ minute values.
- [ ] Default duration is visibly 25 minutes.
- [ ] Timer can be linked to one existing task or no task.
- [ ] Start begins countdown from configured duration.
- [ ] Pause stops decrementing while retaining remaining time.
- [ ] Resume continues from remaining time.
- [ ] Reset stops timer and restores selected configured duration.
- [ ] Only one active countdown loop exists after repeated start/resume.
- [ ] Component cleanup clears timers.
- [ ] Zero crossing stops countdown without negative displayed time.
- [ ] One completed countdown appends exactly one completed session.
- [ ] Session has unique ID, optional task ID, durationMinutes and completedAt.
- [ ] Pause/reset does not record a completed session.

### Persistence and edge cases
- [ ] Settings and completed session history persist after reload.
- [ ] Refresh restores remaining timer snapshot paused.
- [ ] Refresh does not count elapsed wall time or auto-complete a session.
- [ ] Deleting linked task detaches or safely resolves the timer link.
- [ ] History remains readable when its task was deleted.
- [ ] Completion is announced meaningfully without announcing every tick.
- [ ] Storage failure remains visible and does not crash countdown.

### Verification
- [ ] Test duration boundaries and exactly-once completion.
- [ ] Check pause/resume/reset and task deletion.
- [ ] Check reload restores paused remaining time and history.
- [ ] Use executed fake-timer component integration tests for timer lifecycle; no fabricated browser observations.

### Definition of Done
- [ ] Changes committed with genuine history; actual issue linked when available.
- [ ] Independent QA records acceptance evidence; failures fixed before closure.

## Out of scope
Background notifications and cross-device sync.

## Constraints
Depends on 02 and 03; clear interval cleanup and no duplicate sessions.
