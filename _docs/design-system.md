# StudySprint design system

The implemented workspace uses warm ivory page background, dark teal hero and actions, white assignment/form cards, and a pale mint focus panel. Four summary cards distinguish overview, overdue, today and completed using readable text alongside restrained color. Rounded cards, system sans-serif type, generous spacing and subtle borders establish a calm study workspace.

Desktop uses a broad assignment column and a narrower form/focus/backup column. Mobile stacks panels; overview cards become two columns, narrow filter controls stack at the smallest breakpoint. Long task text and historical labels wrap. CSS includes explicit keyboard-visible focus rings. Inputs retain associated labels, field errors use aria-describedby/aria-invalid, buttons use native semantics, and priority/urgency have text labels. Completion and error announcements avoid live ticking.

There are no unsupported sync or notification affordances. The data-location badge describes local device storage. Source and jsdom DOM inspection were performed; actual browser viewport, contrast measurement and visual focus appearance remain external verification tasks rather than claimed observations.
